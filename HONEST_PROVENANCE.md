# Honest provenance statement

## What this is

This repository is a **rebuilt organ**. It implements exactly the
szl-build-env organ contract:

- `GET /healthz` with a W3C traceparent echo (same trace id, fresh sampled
  span id), and
- one exported OTLP span per served request with `service.name=rosie`.

## What this is not

- It is **not** the historical rosie service. The historical source
  repository is unavailable (deleted before this rebuild); its last signed
  historical commit was `97be4e52695e8141036b1c4269a4722148852d4a` and its historical image digest
  was `sha256:1984a15f53c2e1b91c7dafaa0ed5df9148d57e3e86eb73db879c2b0443302848`.
- No claim is made that any historical rosie functionality beyond the organ
  contract above was restored, reproduced, or preserved.
- The historical image did not implement the trace contract; the five-organ
  acceptance could not pass against it. This rebuild exists so the governed
  five-organ trace acceptance can pass honestly, with each span generated by
  the service that actually served the request.

## Supply chain

- Built and keyless-signed only by
  `.github/workflows/ghcr-build-push.yml` on protected main
  (certificate identity recorded by the szl-build-env gate).
- Base image digest-pinned in the Dockerfile.
- No secrets are read, logged, or forwarded by this service.
